PUBLISHING
Upload the complete site folder to your static host. index.html is the homepage. Keep the downloads and images folders beside it.

PROFILE PICTURE
Put a square image named profile.jpg in this site folder, beside index.html. The portrait frame will show it automatically. If you have not added it yet, the page displays a profile-picture placeholder with these instructions.

TEACHERS ONLINE DASHBOARD
The separate Teachers Online Dashboard project card links to https://scoresheet.dev. To change this URL, edit CFG.teachersDashboard near the bottom of index.html.

REXVA DOWNLOAD
Upload the built offline package to downloads/ and name it exactly REXVA-V1.3.0-offline.zip. The download button becomes available when the file is present. See downloads/README.txt for build-package guidance.

SCREENSHOTS
Put the REXVA and teacher-dashboard screenshots in images/ using the exact filenames listed in images/README.txt. Missing screenshots show placeholders automatically.

EXAM VIDEOS
Put MP4 videos in videos/ named students-exam-1.mp4, students-exam-2.mp4, students-exam-3.mp4 (see videos/README.txt). Edit the VIDEOS list near the bottom of index.html to change titles, add more, or use YouTube IDs. Missing videos show a placeholder.

TRIAL REQUESTS
The form collects name, school, contact details and Machine ID. Edit CFG.whatsapp or CFG.email in index.html to route the request to Rexx Hub. If both are blank, the form copies the request text for the visitor to send manually.

OTHER PROJECT LINKS
